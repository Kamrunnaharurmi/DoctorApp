# DoctorApp

A Doctor Appointment Flutter Android app allows users to book appointments with doctors, view doctor profiles, and manage their medical appointments easily. It typically includes features like calling for appointment, hospitals locations,hotline numbers and websites. It also provide a convenient way to manage healthcare needs.
